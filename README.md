# Bright Photography Studio

A responsive, static photography studio website built with HTML, CSS, and vanilla JavaScript. It can be hosted for free on GitHub Pages.

## Files
- `index.html` — full website content and sections
- `css/style.css` — responsive styling, color system, light/dark theme
- `js/main.js` — mobile menu, theme toggle, current year, and email-form behavior
- `assets/favicon.svg` — studio favicon

## Before publishing
1. Replace the illustrative Unsplash images with your own photography where possible.
2. Confirm the contact email and phone number in `index.html` and `js/main.js`.
3. The contact form does not store submissions on a server. It prepares an email in the visitor's mail app using `mailto:`.

## Publish free with GitHub Pages (Android phone)
1. Open https://github.com in Chrome and create a free account or sign in.
2. Tap **+** → **New repository**.
3. Name it `bright-photography-studio`, choose **Public**, and create the repository.
4. Open the new repository. Tap **Add file** → **Upload files**. Upload `index.html`, `css/style.css`, `js/main.js`, and `assets/favicon.svg`, keeping the folder paths exactly as shown. If uploading folders is awkward on mobile, open each folder in the repository and create/upload the file at its matching path.
5. Commit the uploaded files.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**. Select branch `main` and folder `/ (root)`, then tap **Save**.
8. Wait a few minutes and refresh the Pages settings page. Your site address should look like `https://YOUR-USERNAME.github.io/bright-photography-studio/`.

## Notes
- This is a static website; no paid server is needed.
- Google Fonts and the sample photos need an internet connection.
- Replace sample portfolio imagery and any placeholder copy before advertising the site as a real portfolio.
